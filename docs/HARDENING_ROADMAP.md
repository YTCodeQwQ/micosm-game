# Micosm Game 稳定化路线

这份清单跟踪当前八项非验证码问题。每完成一项，都应同时更新状态、测试范围和部署文档。

## 阶段 A：安全与数据

- [ ] 接口滥用防护：为登录、世界频道、匹配和 AI 操作增加可跨实例生效的限流，并返回明确的等待时间。
- [ ] 正式数据库迁移：用版本化迁移覆盖完整 D1 表结构，支持全新部署、升级、回滚和数据校验。
- [ ] 世界频道管理：增加举报审核、禁言、封禁、撤销和操作记录，普通用户端保持轻量。

## 阶段 B：实时与 AI

- [ ] 完整实时化：将好友在线状态、聊天和大厅房间列表从轮询迁移到 Durable Object WebSocket，并保留断线恢复。
- [ ] AI 服务治理：补齐 KataGo/Rapfi 鉴权、健康检查、进程守护、超时降级和资源监控。

## 阶段 C：维护与运维

- [ ] 前端拆分：逐步拆分 `app/page.tsx` 与全局样式，保持现有接口和交互不变，并补视觉回归测试。
- [ ] 生产运维：建立 D1/R2 备份恢复、结构化日志、错误聚合、服务告警和发布回滚流程。

## 阶段 D：真机质量

- [ ] 真机测试矩阵：覆盖 Android、iOS、微信浏览器、弱网切换、后台恢复、扫码权限和桌面安装。

## 已完成的相关基础

- [x] 对局房间使用 Durable Object WebSocket，并保留定时恢复请求。
- [x] 手机端提供浏览器全屏按钮。
- [x] 提供 PWA 清单、桌面图标、Service Worker 和不支持安装时的操作提示。
- [x] 现有逻辑测试、生产构建和双用户接口测试可重复运行。
