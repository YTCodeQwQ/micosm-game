# Micosm Game 稳定化路线

这份清单跟踪当前八项非验证码问题。每完成一项，都应同时更新状态、测试范围和部署文档。

## 阶段 A：安全与数据

- [x] 接口滥用防护：登录、好友、世界频道、匹配和 AI 使用 D1 共享限流桶，并返回 `Retry-After`。
- [x] 正式数据库迁移：统一迁移入口覆盖完整 D1 表结构，`app_schema_migrations` 记录版本并由健康检查验证。
- [x] 世界频道管理：管理员工作台支持举报审核、删除、禁言、封禁、撤销和操作记录。

## 阶段 B：实时与 AI

- [x] 完整实时化：`PlatformHub` 推送好友、聊天和大厅变化，客户端保留 30 至 45 秒恢复轮询。
- [x] AI 服务治理：KataGo/Rapfi 默认仅本机监听，外网强制鉴权，并提供队列上限、指标、健康检查和进程守护。

## 阶段 C：维护与运维

- [x] 前端拆分：移动安装、平台实时连接和频道管理已拆成独立模块，手机关键页面加入像素级视觉回归。
- [x] 生产运维：已提供 D1 备份脚本、结构化 AI 日志、健康探针、告警阈值、CI 和回滚手册。

## 阶段 D：真机质量

- [x] 真机测试矩阵：自动覆盖三档手机宽度，并提供 Android、iOS、微信、弱网、后台恢复、扫码和桌面安装清单。

## 已完成的相关基础

- [x] 对局房间使用 Durable Object WebSocket，并保留定时恢复请求。
- [x] 手机端提供浏览器全屏按钮。
- [x] 提供 PWA 清单、桌面图标、Service Worker 和不支持安装时的操作提示。
- [x] 现有逻辑测试、生产构建和双用户接口测试可重复运行。
