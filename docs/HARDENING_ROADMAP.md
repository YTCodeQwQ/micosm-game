# Micosm Game 稳定化路线

这份清单跟踪当前不含短信验证码接入的稳定化工作。功能发生变化时，应同步更新测试和部署文档。

## 安全与数据

- [x] 登录、好友、世界频道、匹配与 AI 接口使用共享限流，并返回 `Retry-After`。
- [x] D1 使用统一、可重复执行的版本迁移，`/api/health` 校验迁移状态。
- [x] 管理后台支持举报、处罚、撤销与审计记录。
- [x] 内测邀请码由 D1 管理，支持限次、过期和停用。

## 实时与 AI

- [x] `PlatformHub` 推送好友、聊天和大厅变化，客户端保留恢复轮询。
- [x] KataGo 与 Rapfi 默认仅监听本机，非本机监听强制令牌鉴权。
- [x] AI 服务提供队列上限、健康检查、结构化日志与进程守护模板。
- [x] Windows 与 Linux 自动选择对应原生引擎路径。

## 运维与部署

- [x] D1/R2 备份和恢复使用跨平台 Node 命令。
- [x] 提供 Linux systemd、环境变量和反向代理模板。
- [x] Ubuntu CI 执行构建、测试、浏览器检查和跨平台约束测试。
- [x] 部署文档覆盖健康检查、回滚、备份、AI 资产和迁移版本。

## 客户端质量

- [x] 自动覆盖 320、412、430 像素手机宽度。
- [x] 提供 Android、iOS、微信、弱网、后台恢复与桌面安装检查清单。
- [x] 手机端提供全屏与添加到桌面的入口。
- [x] 私人房间使用六位邀请码；二维码创建与扫描功能已经下架。
