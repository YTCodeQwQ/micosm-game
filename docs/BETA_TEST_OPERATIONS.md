# Micosm Game 内测运营说明

## 管理入口

超级管理员进入 `/admin`，打开“内测中心”。这里负责内测身份、注册邀请码、当前排位赛季和玩家反馈。

## 内测环境开关

- 开启后，玩家端品牌区域显示 `BETA`，个人中心开放内测说明与反馈入口。
- 关闭后只取消内测身份展示，不会删除账号、对局或赛季数据。
- “内测反馈”是独立开关；紧急情况下可以暂停新反馈，但玩家仍可查看历史反馈和处理通知。
- 每次切换都会写入管理员审计日志。

## 注册邀请码

- 邀请码支持用途备注、最多使用次数、到期时间和随时停用。
- `0` 次数代表不限次数，`0` 天代表长期有效。
- 注册成功后才永久占用名额；注册写入失败会自动归还名额。
- 早期兼容码 `ABCD123` 会保留在列表中，可由超级管理员直接停用。
- 内测开始后建议为不同测试群分别生成邀请码，便于判断来源和控制名额。

## 内测赛季

- 系统首次初始化会建立“星海内测季”（`S0`）。
- 内测中心只显示当前赛季摘要，所有改名、时间、棋类开放、停止报名和封存操作继续在“对局与排位 > 赛季管理”完成。
- 内测赛季数据可能重置，应在玩家端内测说明和公告中保持一致表述。

## 玩家反馈

- 玩家在“我的 > 内测反馈”提交，可选择问题故障、体验建议、棋类规则、人机对战和其他反馈。
- 每个账号每天最多提交 8 条，防止重复刷入。
- 超级管理员可将反馈设置为待处理、处理中、已解决或已关闭，并填写回复。
- 状态或回复更新后，玩家会收到站内通知，也可以在反馈窗口查看历史记录。

## 上线前交接

1. 停用或删除对外泄露的邀请码，按测试批次生成新码。
2. 确认“开放注册”和“内测环境”开关符合当前阶段。
3. 在赛季管理中检查结束时间、围棋/五子棋开放状态。
4. 发布一条置顶公告，说明测试范围、数据重置可能性和反馈入口。
5. 短信验证码接入后，在注册接口中以短信校验替换邀请码校验；邀请码表可保留用于定向测试，也可停用全部邀请码。
