# 重构围棋对局页面 UI

请重构当前「围棋对局页面」的 UI 布局。

这次不要只调整颜色、圆角、间距，需要重新整理整个页面的信息架构和空间比例。

## 当前页面主要问题

### 1. 棋盘尺寸过大

当前棋盘占据了页面绝大多数视觉空间，导致：

- 左右侧栏被压得非常窄
- 玩家信息字体过小
- 操作按钮空间不足
- 页面整体比例失衡
- 棋盘视觉权重远高于其他重要信息

棋盘应该是页面核心，但不能占据接近整个页面。

建议将棋盘整体缩小约 15%～20%，同时保持正方形和响应式缩放。

---

### 2. 删除左侧固定侧栏

当前左侧存在一个独立的「NOW PLAYING / 围棋」侧栏，其中包含：

- 当前游戏
- 游戏说明
- 已完成局数
- 棋盘规格
- 游戏设置

这些信息不值得永久占据一整列。

请删除这个固定左侧栏。

对应信息重新分配：

- 「围棋」放到顶部标题区域
- 「19 路」放到顶部状态栏
- 「游戏设置」变成顶部设置按钮
- 已完成局数不需要在对局过程中长期显示
- 游戏说明可以放入规则弹窗

不要为了保留这些信息而继续创建新的大型侧栏。

---

## 新页面整体结构

将当前：

```text
左侧栏 | 巨大棋盘 | 右侧栏
```

改为：

```text
顶部对局状态栏

主棋盘区域 | 对局信息侧栏

底部操作栏
```

推荐结构：

```text
┌─────────────────────────────────────────────────┐
│ ← 围棋     ● 语天QwQ  VS  ○ KataGo      ⚙ 设置 │
│            你的回合 · 第 19 手 · 19路            │
├──────────────────────────────────┬──────────────┤
│                                  │              │
│                                  │   对局信息    │
│                                  │              │
│                                  │ ● 语天QwQ     │
│             棋盘                 │ ○ KataGo     │
│                                  │              │
│                                  │ 当前比分      │
│                                  │              │
│                                  │ 贴目 / 规则   │
│                                  │              │
│                                  │ 落子记录      │
│                                  │              │
├──────────────────────────────────┤              │
│   悔棋      停一手      认输      │              │
│              [确认落子]           │              │
└──────────────────────────────────┴──────────────┘
```

# 顶部区域

顶部应该变成真正的「对局状态栏」。

展示最重要的信息：

- 返回按钮
- 游戏名称：围棋
- 黑方玩家
- 白方玩家
- 当前回合
- 当前手数
- 棋盘规格
- 设置按钮

例如：

```text
← 围棋

● 语天QwQ   VS   ○ KataGo

你的回合 · 第 19 手 · 19路                 ⚙
```

当前回合需要明显突出。

例如：

```text
你的回合
```

可以使用轻量高亮背景或者状态色。

不要再把当前回合信息分散在多个区域重复显示。

---

# 棋盘区域

棋盘仍然是整个页面的视觉中心。

但是：

- 不要铺满整个中间区域
- 不要无限放大
- 不要为了填满 viewport 强制拉大棋盘
- 保持合理最大尺寸

建议：

```css
width: min(65vw, 720px);
aspect-ratio: 1 / 1;
```

具体数值可以根据现有页面适配。

棋盘周围保持适当留白。

不要出现棋盘几乎贴满卡片边缘的情况。

---

# 删除顶部 Banner

当前棋盘上方存在一条类似：

```text
CELESTIAL MATCH
```

的装饰 Banner。

这条 Banner 对实际游戏没有帮助，并且占据宝贵的纵向空间。

请删除。

如果需要保留氛围元素，可以使用非常轻量的背景装饰，而不是增加一个独立 Banner 区域。

---

# 右侧对局信息栏

右侧不要再做成一个巨大但内容稀疏的空白面板。

宽度建议：

```text
280px ～ 340px
```

里面按顺序放：

## 玩家信息

```text
● 语天QwQ
黑方
当前回合

○ KataGo
白方
AI
```

玩家头像、名称、棋子颜色应该清晰可见。

---

## 当前比分

例如：

```text
比分

● 黑棋        0
○ 白棋        0
```

不要使用过小字号。

---

## 对局规则

简化成：

```text
中国规则
贴目 7.5
19 路
```

详细规则放到弹窗中。

不要在侧栏里面塞大段说明文字。

---

## 落子记录

把空出来的空间真正利用起来。

展示最近几手：

```text
落子记录

19. 黑 Q10
18. 白 D16
17. 黑 R4
16. 白 C3
...
```

如果未来有完整棋谱功能，可以让这里支持滚动。

这样右侧区域即使游戏进行中也不会显得非常空。

---

# 底部操作栏

现在最重要的游戏操作被压缩在非常小的一条区域里。

请重新设计。

主要操作：

```text
悔棋
停一手
认输

确认落子
```

其中：

```text
确认落子
```

必须是主按钮。

视觉权重最高。

例如：

```text
[ 悔棋 ]   [ 停一手 ]   [ 认输 ]

          [ 确认落子 ]
```

或者：

```text
悔棋    停一手    认输           [ 确认落子 ]
```

不要把所有按钮都设计成相同视觉等级。

---

# 「重新开始」按钮

当前页面右下角存在一个巨大黑色「重新开始」按钮。

这个按钮：

- 位置突兀
- 视觉权重过高
- 容易误操作
- 对进行中的棋局来说不是高频操作

请移除这个大按钮。

改成：

```text
更多 ⋯
```

菜单里面：

```text
重新开始
退出对局
查看规则
```

如果用户点击重新开始，需要二次确认。

---

# 减少 Card 套 Card

当前页面存在大量：

```text
页面卡片
  ↓
内部卡片
  ↓
子卡片
  ↓
按钮卡片
```

的问题。

请减少不必要的：

- 边框
- 圆角
- 背景块
- 阴影

原则：

只有真正属于独立信息区域的内容才使用 Card。

例如：

可以有：

```text
棋盘区域
对局信息区域
```

但不要每一条玩家信息、规则、状态都再包一个独立 Card。

---

# 提高视觉层级

当前 UI 整体过于浅：

```text
浅蓝背景
浅灰卡片
浅灰边框
浅灰文字
```

导致所有元素视觉权重接近。

请重新建立层级。

推荐：

### 一级信息

例如：

```text
围棋
你的回合
玩家名字
比分
```

颜色明显更深。

### 二级信息

例如：

```text
第 19 手
19路
黑方
白方
```

正常灰色。

### 三级信息

例如：

```text
辅助说明
规则描述
```

使用浅灰。

不要让所有文字都使用同一个低对比度灰色。

---

# 棋盘颜色

保留传统木质棋盘风格。

不需要彻底修改棋盘颜色。

但是目前棋盘视觉重量太大，因此可以适当降低：

- 棋盘饱和度
- 棋盘外框厚度
- 棋盘阴影强度

让棋盘与浅色 UI 更协调。

不要改变棋盘线条、星位和棋子逻辑。

---

# 页面高度

非常重要：

不要继续使用这种设计：

```css
height: 100vh;
```

然后强制：

```text
左侧栏撑满
中间撑满
右侧栏撑满
```

页面应该根据内容合理布局。

如果浏览器高度不足，可以正常滚动。

不要为了「看起来填满屏幕」制造大量空白。

---

# 不允许修改的内容

本次只做 UI / UX 重构。

不要修改：

- 围棋规则逻辑
- 落子逻辑
- KataGo 接口
- AI 对战逻辑
- WebSocket
- 游戏状态管理
- API
- 棋盘坐标逻辑
- 当前已有功能

尽量复用现有：

- React 组件
- 状态
- API
- CSS
- UI 元素

必要时可以拆分 UI 组件，但不要为了重构界面大规模重写业务代码。

# 最终目标

用户进入对局页面后，视觉顺序应该非常明确：

```text
1. 我在和谁下棋
2. 现在轮到谁
3. 棋盘
4. 我要进行什么操作
5. 当前比分 / 状态
6. 最近的落子记录
```

而不是：

```text
左边一个空侧栏
+
中间一个巨大棋盘
+
右边一个空侧栏
```

最终效果应该更像一个真正的「在线围棋对局界面」，而不是把围棋棋盘塞进后台管理 Dashboard 模板。

完成后请重点检查：

1. 左侧固定侧栏是否已经删除。
2. 棋盘是否不再占据几乎整个页面。
3. 当前回合是否一眼可见。
4. 玩家双方信息是否清晰。
5. 确认落子是否成为主要操作。
6. 右侧是否不再存在大片无意义空白。
7. 是否减少了 Card 套 Card。
8. 是否删除了顶部装饰 Banner。
9. 是否移除了右下角巨大「重新开始」按钮。
10. 是否保留了所有原有业务功能。
